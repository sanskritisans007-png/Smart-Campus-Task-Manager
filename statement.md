# Project Statement

## Problem Statement
Students often track assignments, projects, examinations and personal deadlines across different notes and applications. This makes it difficult to search tasks, identify overdue work and maintain a single persistent record. The Smart Campus Task Manager provides a simple command-line solution for creating and managing these tasks.

## Scope
The system focuses on local task management through a Java CLI. It supports CRUD-style task operations, searching, sorting, analytics, deadline reminders and CSV persistence. It does not include cloud synchronization, authentication or a graphical interface.

## Target Users
- University students
- Student project teams
- Users who prefer a lightweight command-line task manager

## High-Level Features
1. Task creation and validation
2. Task listing, completion and deletion
3. Search and sorting
4. Analytics/report generation
5. Deadline reminder using a separate thread
6. Persistent CSV storage
7. Custom exception handling
